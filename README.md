# AI Multilingual Course Guidance Telecaller

A Django prototype of an outbound course-guidance call. The student speaks, and an AI voice replies in the student's own language: English, Tamil, Telugu or Hindi. Every conversational reply is generated by a large language model (Google Gemini by default) using the approved course catalogue. There are no scripted or keyword-based answers. See [the project submission](PROJECT_SUBMISSION.md) for the full design.

## How it works

1. A counsellor adds an enquiry with the student's contact permission and presses **Call**.
2. The browser captures the student's speech (Chrome speech recognition) and sends the text to Django.
3. `guidance/ai.py` sends the model the instructions, the catalogue, the call stage, the profile collected so far and the recent conversation. The model returns its spoken reply with structured updates, such as the language, consent, profile details, recommended course, unanswered question, callback request and end of call.
4. Django validates the model's output before saving it:
   - Course IDs must exist in the catalogue.
   - Any rupee amount in the reply must be a catalogue fee. Otherwise the model is asked to correct itself.
   - Languages must be supported.
   - Turns use optimistic revision checks.
5. The reply is spoken with a neural voice (`edge-tts`) in the student's language, and the microphone listens again.
6. **Counsellor reports** show each call with the profile, recommended course, questions the AI could not confirm and callback requests.

Only button actions (opt-out, stop and saving a callback) use fixed confirmation text. If the model cannot be reached, the student hears a short request to repeat, and the bubble is marked as a fixed message.

## Run locally

```powershell
python -m pip install -r requirements.txt
python run.py --port 8000
```

`run.py` applies the Django migrations and starts the server. The standard Django commands work too:

```powershell
python manage.py migrate
python manage.py runserver 8000
```

Either way, Django reads the AI key from `.env`. Open **http://127.0.0.1:8000** in Google Chrome.

### AI key

Create a `.env` file next to `run.py`. A free Gemini key from [Google AI Studio](https://aistudio.google.com/apikey) is enough. `.env` is ignored by git.

```
GEMINI_API_KEY=your-key
GEMINI_MODEL=gemini-flash-lite-latest
# Optional backup: a free Groq key from https://console.groq.com/keys
GROQ_API_KEY=
GROQ_MODEL=qwen/qwen3.8-27b
# Optional: an OpenAI key takes priority when set (API billing is separate from ChatGPT Plus)
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
```

The first configured provider (OpenAI, Gemini, then Groq) writes the replies. The next one is a backup: if the main model fails, hits its rate limit or takes longer than 9 seconds, the backup answers the same turn. The free Gemini tier allows about 15 requests per minute, which is about one call at a time.

## Try a call

1. Add a fictional enquiry with PLC as the interest and tick **Contact permission granted**.
2. Keep **Auto-detect** selected, with **Hands-free call** and **Read replies aloud** on, and press **Call**.
3. Say "Tamil", "vanakkam" or "Hindi mein baat karo" to switch language, then answer naturally. The AI asks about your education, experience, interests and goal, recommends a course with its fee and duration, and answers questions.
4. Ask something the catalogue does not cover, such as weekend batches. The AI says it cannot confirm it and offers a counsellor callback.
5. Open **Counsellor reports** and press **View** to see the summary.

## Tests

```powershell
python manage.py test guidance
```

The tests replace the model with scripted outputs. They check the consent and discovery flow, the saved recommendation, catalogue grounding (an invented fee is corrected), rejection of unknown courses, unanswered questions, callbacks, decline, opt-out suppression, model-failure fallback and stale revisions.

## Project layout

| Path | Purpose |
|---|---|
| `telecaller/` | Django settings and URLs |
| `guidance/models.py` | Enquiry, Suppression and CallSession models |
| `guidance/ai.py` | Prompt, model call and validation of the model's output |
| `guidance/views.py` | JSON API, call flow, speech and logging endpoints |
| `guidance/templates/guidance/dashboard.html` | Voice dashboard UI |
| `catalogue.json` | Approved sample course catalogue |

## Deployment scope

The prototype runs on localhost with fictional data. Browser speech simulates the phone channel. Live outbound dialling through a telephony provider, DND and calling-hours checks, dashboard authentication and production privacy controls require further work. See the submission for the production architecture.
